# coding_hsg

Documentation: [documentation.md](documentation.md)

## Run locally
1. Clone the repository: `git clone https://github.com/lucameriano/coding_hsg`
2. Navigate into the folder: `cd coding_hsg`
3. Install dependencies: `pip install numpy matplotlib pandas sortedcontainers xgboost scikit-learn` or `uv pip install numpy matplotlib pandas sortedcontainers xgboost scikit-learn` 
4. Run the notebook: open `prediction.ipynb` in Jupyter or VS Code
